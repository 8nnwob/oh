# 字日 Words — 每日單字練習

一個輕量、免安裝的每日英文單字練習頁面。使用瀏覽器本機儲存記錄進度，透過簡單的間隔複習安排舊字與新字。

## 使用方式

直接開啟 `index.html`，或透過 GitHub Pages 發布。今天的練習會先包含到期複習，再依每日設定加入 3、5 或 8 個新字（若字庫剩餘新字不足，實際數量會較少）。翻開單字卡後選「熟悉」或「再練一次」，頁面會在瀏覽器本機記錄結果。

## 發布到 GitHub Pages

1. 將此專案推送到 GitHub repository 的 `main` 或 `master` 分支。
2. 在 repository 的 **Settings → Pages → Build and deployment** 中，將 Source 設為 **GitHub Actions**。
3. 每次推送到上述分支，`.github/workflows/pages.yml` 會自動部署網站；也能從 Actions 頁面手動執行。

學習資料存在目前瀏覽器的 `localStorage`，不會同步到其他裝置。重設按鈕可清除本機進度。

## 練習題型

首頁字卡可切換「英翻中」與「中翻英」方向；選擇保存在目前瀏覽器，並以揭曉答案後的熟悉度回饋作為簡單的主動回想練習。

每日新字數可設定為 3、5 或 8 個，預設為 5 個；調整會從下一日建立佇列時生效，今天已開始的練習維持原樣。

新字也可依「溝通表達、思考判斷、成長行動」主題篩選；主題只影響尚未學過的新字，已到期的複習字仍照常安排。主題變更從下一日開始生效。

單字卡會顯示已核對的 CEFR 詞彙等級；沒有可靠標記的字不會自行推估。標籤來源和核對範圍見 [`knowledge/vocabulary-sources.md`](knowledge/vocabulary-sources.md)。

支援瀏覽器語音合成時，可按「聽發音」播放英文讀音。中翻英尚未揭曉答案時不會顯示發音按鈕，以免提前聽到答案。

## 備份與移轉

頂端的「匯出進度」會下載 JSON 備份；「匯入進度」可在確認後取代目前瀏覽器的進度。備份包含字詞熟悉度、連續練習天數、每日設定與當日佇列。請妥善保存匯出的檔案；它只會在使用者操作時下載或讀取，不會上傳到伺服器。
