# 每日單字訓練系統計畫

## 願景

打造一個每天陪伴使用者學習與記憶單字的系統。系統每日派發適量的新字，並依照記憶狀況安排複習，讓詞彙能循序累積。每張單字卡提供音標、中文解釋、例句、近義字與用法等資訊，並透過練習和學習紀錄協助使用者掌握進度。

## 路線圖

### 目前狀態

- 已完成可操作的純前端原型：每日最多五個新字，先複習到期字，字卡包含音標、詞性、中文解釋、例句、近義字及用法。
- 使用者可標記熟悉或明天再練；當日佇列與進度保存在本機，完成整份練習後更新連續練習天數。
- 已建立 GitHub Actions Pages 部署流程及操作說明，但目前只有本機工作樹，尚未建立遠端或完成首次發布。
- 預設採通用中高階示範字庫，不代表正式程度分級；個人紀錄存放在瀏覽器 `localStorage`，不跨裝置同步。
- GitHub 遠端建立／推送仍待 GitHub 帳號連線；其餘前端改進與文件整理可持續進行。
