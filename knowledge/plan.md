# 每日單字訓練系統計畫

## 願景

打造一個每天陪伴使用者學習與記憶單字的系統。系統每日派發適量的新字，並依照記憶狀況安排複習，讓詞彙能循序累積。每張單字卡提供音標、中文解釋、例句、近義字與用法等資訊，並透過練習和學習紀錄協助使用者掌握進度。

## 路線圖

### 目前狀態

- 純前端原型支援每日新字數量設定、主題篩選、到期複習、英翻中／中翻英回想及本機進度記錄。
- 每日佇列和作答位置會保存；配額與主題設定從下一日生效；完成整份練習後才更新連續練習天數。
- GitHub Actions Pages workflow 已備妥，但尚無 GitHub 遠端，亦未執行首次部署。
- 字庫是通用示範內容，主題分類不代表正式程度分級；個人紀錄保存在目前瀏覽器，不跨裝置同步。
